# Landil v2 MVP (read-only)

Guests browse published listings on Android, iOS and the web. The Rust API reads the v1 database and never writes to it.

## Run locally

Needs Docker, Rust 1.98 or later, and Node 26 LTS (`.nvmrc`).

```bash
make setup   # one time: install app dependencies
make api     # starts the test database (Postgres 17, v1 schema, test data) and the API on :8080
make app     # in a second terminal: w = web, a = Android, QR code = Expo Go
```

On a phone, run `make app API_URL=http://<LAN IP of your computer>:8080`. Run `make` to see all targets.

## API

| Route | Result |
| -- | -- |
| `GET /health` | 200 when the database answers |
| `GET /v1/listings?q=&type=&price=&cursor=&limit=` | Published listings, newest first, 20 per page, with `next_cursor` |
| `GET /v1/listings/{id}` | One published listing: photos, public documents and the number of private documents |

`CORS_ORIGINS` (comma-separated) sets the allowed website origins. The default is `http://localhost:8081`.

## Web build

`make web` builds the static website and serves it with Caddy on http://localhost:8081.
